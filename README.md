
# Data Science Learning Roadmap

Repository ini berisi perjalanan belajar dan pengembangan skill **Data Science** dari dasar hingga membangun project end-to-end.

Materi disusun secara bertahap mulai dari Python fundamentals, Exploratory Data Analysis (EDA), Statistical Analysis, Machine Learning, hingga implementasi project dan deployment menggunakan Streamlit.

---

## 🎯 Learning Goals

Tujuan utama repository ini adalah membangun pemahaman dan kemampuan praktis dalam:

- Python Programming
- Data Analysis
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistics for Data Science
- Feature Engineering
- Classical Machine Learning
- Model Evaluation
- Model Deployment
- Streamlit
- Git & GitHub
- End-to-End Data Science Project

## 🚀 End-to-End Data Science Projects

Folder `projects/` digunakan untuk menyimpan project Data Science yang dikerjakan secara end-to-end.

Typical project workflow:

```text
Business Problem
       ↓
Data Collection
       ↓
Data Understanding
       ↓
Data Cleaning
       ↓
Exploratory Data Analysis
       ↓
Feature Engineering
       ↓
Model Development
       ↓
Model Evaluation
       ↓
Model Selection
       ↓
Deployment
       ↓
Monitoring / Improvement
```
